# Changelog

All notable updates to the Three Kingdoms Archive are documented here, newest first.

V2 versioning follows `v2.YY.MM(a,b,c...)` (version, year, month, and a letter
suffix for multiple releases within the same month). A `-hf` suffix denotes a
hotfix for bugs.
